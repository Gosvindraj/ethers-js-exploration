# Ethers.js by Example - Tutorial by DappUniversity Youtube Channel

Learn how to use ethers.js from these examples

## Technology Stack & Tools Learnt

- Javascript (Writing scripts)
- [Ethers.js](https://docs.ethers.io/v5/) (Blockchain Interaction)
- [Node.js](https://nodejs.org/en/) (To run our scripts and install ethers.js)
- [Infura](https://infura.io/) (Node provider)

## Ethers.js scripts

- 1_accounts.js - Reads balance of ether of wallet address
- 2_read_smart_contract.js - Reads the balance of a wallet address from the USDC contract
- 3_send_signed_transaction.js - Transfers 0.001 ether from account1 to account2
- 4_deploy_contract.js - Deploys contract on Sepolia testnet by using Factory contract
- 5_write_contract.js - Transfers entire balance of LINK token from account1 to account2 (on Sepolia testnet)
- 6_contract_event_stream.js - Queries a block for transfer events
- 7_inspecting_blocks.js - Get transactions from block
